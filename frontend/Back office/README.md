# NephroCare staff application

Angular app for clinicians and operations staff. The UI shell started from the TailAdmin Angular template. NephroCare screens cover clinical follow-up, dialysis, pharmacy, orders, hospitalization, and the kidney CT scan.

Local API: `http://localhost:8070`. Keycloak: `http://localhost:8180`. The dev server listens on port 4369.

```bash
npm ci
npm start
```

The project overview is in the repository root README.
